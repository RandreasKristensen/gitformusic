# git for music project description

git-like solution for versioning and sharing music projects cross platform, p2p networking. Hub for sharing like github.
We host the collaboration. You own the files.

This repository only consist of the Rust core and angular frontend, the C# backend and cloud is hosted and proprietary.

## Tech stack

- Rust storage/versioning core distributed project/versioning engine
    - with C++ JUCE interface
- UI in Angular (over JUCE UI)
- Backend / Cloud in C# (Private, another repo)
